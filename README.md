# Material Symbols for Tailwind CSS

[Material Symbols](https://fonts.google.com/icons) as Tailwind CSS utilities, with self-hosted fonts, automatic subsetting in your bundler and icons as classes instead of ligature text. For Tailwind CSS v4 (v3 is deprecated).

```html
<span class="icon icon-symbol-favorite icon-fill"></span>
```
